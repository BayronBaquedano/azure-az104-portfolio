# Project 04 – Azure Storage Account

This project focuses on Azure Storage Account configuration and secure access patterns.

## What was implemented
- General Purpose v2 Storage Account
- Blob containers with different access levels
  - Public container for static assets
  - Private container for sensitive data
- Blob upload and access validation
- Secure access using Shared Access Signatures (SAS)
- Network-level access restriction

## Key concepts demonstrated
- Difference between public and private containers
- Secure temporary access using SAS tokens
- Access Keys vs SAS best practices
- Network security for storage accounts

## Skills covered
- Azure Blob Storage
- Storage security
- Access control
- AZ-104 relevant storage scenarios
