# Azure Mini Infrastructure FitApp

This project documents a small Azure infrastructure for a booking application. The solution is built with Bicep and includes a web application, network segmentation, Azure SQL, a Private Endpoint, and an NSG.

## Project structure
- `app/` application source code
- `bicep/` infrastructure as code
- `docs/` project documentation
- `architecture/` diagrams
- `screenshots/` validation evidence
